# KomaScope

[English](./README.md) | **简体中文**

针对 **4K 分辨率(3840×2160)屏幕**优化的开源轻量桌面漫画阅读器。以接近原始分辨率的清晰度逐页阅读本地漫画图片,离线可用,单机工具。基于 [MIT](./LICENSE) 许可证开源。

> **当前状态**:v0.2.0 已发布 — Electron + TypeScript 应用可运行(`pnpm dev`)。支持:文件夹/压缩包(zip/cbz)浏览(自然排序)、拖拽导入、首屏渲染、翻页与双页跨页、拖拽平移、光标锚点滚轮缩放、五种适配模式、缩放锁定、长图模式(单页无限下拉 + Ctrl+滚轮缩放)、书签与阅读进度记忆、图片旋转与镜像、HiDPI 适配(DPR 画布 + UI 缩放系数)、超大图瓦片渲染(>8192px)、相邻页预解码、配置持久化、**无边框窗口**(默认,沉浸模式 = 非全屏无边框,可重建有边框查看系统菜单)、**侧栏**(历史文件夹管理 + 图片列表 + 可调占比)、**自动隐藏 UI**、lucide 图标、双语应用菜单与中英文切换。核心纯逻辑(变换模型、自然排序、图片尺寸、窗口几何、瓦片 LRU 与网格、i18n、压缩包解析)均有单测覆盖(70 项);GitHub Actions CI/CD(日常测试 + v* tag 自动构建发布)与社区文件已就位。详细开发方案见 [DEVELOPMENT.md](./DEVELOPMENT.md)(英文版见 [DEVELOPMENT.en.md](./DEVELOPMENT.en.md))。

## 核心特性

- **高清阅读**:漫画图片以接近原始分辨率呈现,HiDPI(100% / 125% / 150% / 200%)下无模糊;超大图(超过 GPU 纹理上限)自动启用瓦片渲染
- **文件夹与压缩包**:打开本地文件夹或 **zip/cbz 压缩包**,按文件名**自然排序**(`page2 < page10`)逐页阅读,支持 jpg / png / webp / gif / bmp / avif
- **拖拽导入**:拖入图片文件、整个文件夹或压缩包即可打开
- **灵活缩放**:滚轮以光标为锚点缩放,支持 `适应宽度` / `适应高度` / `适应屏幕` / `实际大小(1:1)` / `自定义缩放` 五种模式
- **锁定缩放比例**:等比锁定(默认,宽高始终同比例,杜绝变形)+ 可切换的缩放锁定(冻结当前倍率,仅可平移)
- **平移与翻页**:左键拖拽平移,`←`/`→` 翻页,双击在适应屏幕与自定义缩放间切换;支持双页跨页阅读
- **长图模式**:一键将所有图片垂直拼接成单页无限下拉长条,普通滚轮滚动浏览、`Ctrl+滚轮` 缩放(50%–400%),点击任意图片跳转到该页
- **无边框窗口**:默认无边框(隐藏标题栏/系统菜单),工具栏可拖动 + 自绘最小化/最大化/关闭按钮;沉浸模式 = 非全屏无边框,退出后重建有边框窗口以便访问系统菜单;`F11` 为 OS 全屏
- **侧栏管理**:最近打开的文件夹/压缩包历史(可单独删除、点击重开)+ 当前来源图片列表(点击跳页);历史/图片区块占比可拖拽调整
- **自动隐藏 UI**:默认开启,侧栏/工具栏/状态栏浮动隐藏,鼠标移近屏幕边缘唤出
- **窗口记忆**:窗口位置/大小持久化,多显示器下按显示器记忆
- **性能友好**:预解码 + LRU 解码缓存(默认 8 页),4K 视口内平移/缩放目标 ≥30fps
- **完全离线**:无任何网络依赖

## 技术方案

| 层 | 选型 |
| --- | --- |
| 桌面框架 | Electron 33+(Chromium 原生 4K / HiDPI 渲染) |
| 语言 | TypeScript 5 |
| 构建 | electron-vite + electron-builder(NSIS / dmg) |
| 渲染 | HTML5 Canvas 2D(精确控制 DPR 与瓦片),UI 面板用 DOM,不引入重型框架 |
| 图片解码 | 浏览器原生 `createImageBitmap()`(Web Streams 流式解码,不阻塞主线程) |
| 压缩包解析 | fflate(流式解压 zip/cbz,带资源上限防 zip 炸弹) |
| 配置持久化 | 自写 JSON,存于 `userData/config.json` |
| 安全基线 | `contextIsolation: true`、`sandbox: true`,渲染进程无 Node 权限,文件访问全部经主进程 |

## 快捷键

| 按键 | 行为 |
| --- | --- |
| `←` / `→` | 上一页 / 下一页 |
| `+` / `-` | 放大 / 缩小(锚点 = 视口中心) |
| `0` | 适应屏幕 |
| `1` | 实际大小 1:1 |
| `W` / `H` | 适应宽度 / 适应高度 |
| `L` | 切换缩放锁定 |
| `R` | 重置视图(居中 + 适应屏幕) |
| `F` / `F11` | OS 全屏切换 |
| `Esc` | 退出沉浸/全屏 |
| 滚轮(视口) | 以光标为锚点缩放(锁定状态下忽略) |
| 滚轮(侧栏) | 上下切换图片(上一页/下一页) |
| 滚轮(长图模式) | 滚动浏览长条图片 |
| `Ctrl+滚轮`(长图模式) | 缩放长图(50%–400%) |
| 左键拖拽 | 平移图片 |
| 双击 | 在适应屏幕与上一次自定义缩放间切换 |
| 拖入文件/文件夹/压缩包 | 打开对应图片/目录 |
