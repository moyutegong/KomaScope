# KomaScope

[English](./README.md) | **简体中文**

针对 **4K 分辨率(3840×2160)屏幕**优化的开源轻量桌面漫画阅读器。以接近原始分辨率的清晰度逐页阅读本地漫画图片,离线可用,单机工具。基于 [Apache-2.0](./LICENSE) 许可证开源。

> **当前状态**:全部里程碑 M0–M5 已完成 — Electron + TypeScript 应用可运行(`pnpm dev`);文件夹浏览(自然排序)、拖拽导入、图片尺寸解析、首屏渲染、翻页、拖拽平移、光标锚点滚轮缩放、五种适配模式、缩放锁定、全部快捷键、HiDPI 适配(DPR 画布 + UI 缩放系数)、超大图瓦片渲染(>8192px)、相邻页预解码、配置持久化与 NSIS 打包(`pnpm build:win`)均可用。核心纯逻辑(变换模型、自然排序、图片尺寸、窗口几何、瓦片 LRU 与网格)均有单测覆盖;GitHub Actions CI/CD 与社区文件(Issue 模板、行为准则)已就位。详细开发方案见 [DEVELOPMENT.md](./DEVELOPMENT.md)(英文版见 [DEVELOPMENT.en.md](./DEVELOPMENT.en.md))。

## 核心特性

- **高清阅读**:漫画图片以接近原始分辨率呈现,HiDPI(100% / 125% / 150% / 200%)下无模糊;超大图(超过 GPU 纹理上限)自动启用瓦片渲染
- **文件夹浏览**:打开本地文件夹,按文件名**自然排序**(`page2 < page10`)逐页阅读,支持 jpg / png / webp / gif / bmp / avif
- **拖拽导入**:拖入图片文件或整个文件夹即可打开
- **灵活缩放**:滚轮以光标为锚点缩放,支持 `适应宽度` / `适应高度` / `适应屏幕` / `实际大小(1:1)` / `自定义缩放` 五种模式
- **锁定缩放比例**:等比锁定(默认,宽高始终同比例,杜绝变形)+ 可切换的缩放锁定(冻结当前倍率,仅可平移)
- **平移与翻页**:左键拖拽平移,`←`/`→` 翻页,双击在适应屏幕与自定义缩放间切换
- **窗口记忆**:窗口位置/大小持久化,多显示器下按显示器记忆;支持 F11 全屏阅读
- **性能友好**:预解码 + LRU 解码缓存(默认 8 页),4K 视口内平移/缩放目标 ≥30fps
- **完全离线**:无任何网络依赖

## 技术方案

| 层 | 选型 |
| --- | --- |
| 桌面框架 | Electron 33+(Chromium 原生 4K / HiDPI 渲染) |
| 语言 | TypeScript 5 |
| 构建 | electron-vite + electron-builder(NSIS / dmg) |
| 渲染 | HTML5 Canvas 2D(精确控制 DPR 与瓦片),UI 面板用 DOM,不引入重型框架 |
| 图片解码 | 浏览器原生 `createImageBitmap()`(Web Streams 流式解码,不阻塞主线程) |
| 配置持久化 | `electron-store`(或自写 JSON),存于 `userData/config.json` |
| 安全基线 | `contextIsolation: true`、`sandbox: true`,渲染进程无 Node 权限,文件访问全部经主进程 |

## 快捷键

| 按键 | 行为 |
| --- | --- |
| `←` / `→` | 上一页 / 下一页 |
| `+` / `-` | 放大 / 缩小(锚点 = 视口中心) |
| `0` | 适应屏幕 |
| `1` | 实际大小 1:1 |
| `W` / `H` | 适应宽度 / 适应高度 |
| `L` | 切换缩放锁定 |
| `R` | 重置视图(居中 + 适应屏幕) |
| `F` / `F11` | 全屏切换 |
| `Esc` | 退出全屏 / 关闭设置面板 |
| 滚轮 | 以光标为锚点缩放(锁定状态下忽略) |
| 左键拖拽 | 平移图片 |
| 双击 | 在适应屏幕与上一次自定义缩放间切换 |
| 拖入文件/文件夹 | 打开对应图片/目录 |
